Passo 8 · CSS

Organização dos estilos

Um arquivo único de 6.000+ linhas dividido por área — mais fácil de manter.

css/
├── base.css        ← cores, tipografia, header
├── layout.css      ← sidebar, bottom bar, drawers
├── indicadores.css ← abas, painéis, formulários
├── pdf.css         ← importação e resultados
└── simulador.css   ← nota final
